# Merry Christmas · 电子圣诞树

可装饰的 WebGL 电子圣诞树，单文件零依赖。

## 在线版

https://lewis0821.github.io/christmas-tree/

## 玩法

- **调色板**：6 套配色（冰蓝 / 霜夜 / 玫瑰 / 鎏金 / 薰衣草 / 樱粉），快捷键 `P`，或按 `1`-`6` 切换
- **装饰圣诞树**：点「装饰」（或按 `D`）进入装饰模式，选彩球 / 星星 / 礼物 / 铃铛 + 8 种颜色，点树上任意位置放置
- **永久链接**：装饰完点「复制永久链接」，色彩和每件装饰都编码在 URL 里
- **许愿**：点击空白处绽放光点

## 技术

纯 WebGL 运行时程序化生成，无第三方库、无外部请求。装饰状态压缩进 URL hash，纯前端即可分享。
